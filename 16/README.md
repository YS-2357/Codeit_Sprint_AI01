# 🚀 Mission 16: 모델 최적화 및 변환 실습

## 📝 미션 개요

지금까지 AI 스프린트 미션을 통해 다양한 모델을 학습 및 구현해보셨습니다.  
이번 미션에서는 그 모델들을 다시 가져와 **여러 형태의 포맷으로 변환하고 저장**하는 실습을 진행합니다.

---

## ✅ 미션 요구사항

### 1. 모델 학습

- 이전 미션에서 다루었던 모델 중 **하나 이상**을 자유롭게 선택하여 학습을 진행합니다.

### 2. 모델 변환 및 저장

다음 **3가지 포맷**으로 모델을 변환하여 저장합니다:

- `.pth` (PyTorch 기본 저장 형식)
- `.pth` (양자화된 버전)
- `.onnx` (ONNX 형식)

### 3. 모델 추론 코드 작성

- ONNX 파일을 기반으로 추론 코드를 작성합니다.
- 적절한 **평가 데이터셋**을 사용하여 모델의 동작을 검증합니다.

---

## 📦 제출 안내

### 디렉토리 구조

`미션 16` 폴더 하위에 다음과 같은 이름으로 폴더를 생성합니다:
`{팀명}_{이름}/`

### 포함 항목

1. `modeling.ipynb`: 모델 학습 및 변환 코드
2. `inference.ipynb`: 모델 추론 코드
3. `요약 보고서 PDF`
4. 변환된 모델 파일들:
   - `mission_16_{model_name}.pth`
   - `mission_16_{model_name}_quantized.pth`
   - `mission_16_{model_name}.onnx`
5. 변환된 모델들과 파일 크기를 한눈에 확인할 수 있는 **이미지 캡처**
6. 디버깅 및 오류 해결 과정 정리

> 📁 모든 파일을 하나의 `.zip`으로 압축하여 제출합니다.

## 웹 서버 실행

1. 디렉토리(`js_demo`)로 이동합니다.
2. Python 내장 HTTP 서버를 사용해 웹 서버를 실행합니다:

```bash
cd js_demo
python -m http.server 8080
```

3. 웹 브라우저에서 아래 주소로 접속합니다:

```bash
http://localhost:8080
```

4. 웹 페이지에서 **숫자 이미지 업로드** 또는 직접 입력을 통해 모델 예측을 확인할 수 있습니다.
5. 예측 결과는 웹 페이지 하단의 `결과:` 영역에 출력됩니다.
