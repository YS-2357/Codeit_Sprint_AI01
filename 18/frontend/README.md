# 🎬 Streamlit 프론트엔드 - 영화 리뷰 감성 분석 App

## 📌 프로젝트 개요

본 프론트엔드는 FastAPI 기반 백엔드와 연동하여,  
**영화 정보 등록**, **리뷰 작성 및 감성 분석**, **리뷰 조회** 기능을 제공하는 웹 애플리케이션입니다.  
Streamlit을 활용하여 간편하고 직관적인 사용자 인터페이스를 구축했습니다.

---

## 🧭 주요 기능

### 1. 📽️ 영화 등록 및 목록 조회
- 영화 제목, 감독, 장르, 평점, 포스터 URL 입력 후 등록 가능
- 등록된 영화는 카드 형식으로 이미지, 정보와 함께 나열
- 등록 성공 시 자동으로 영화 목록 갱신

### 2. ✏️ 리뷰 등록 및 감성 분석
- 선택한 영화에 대해 리뷰 작성 가능
- 작성한 리뷰는 자동으로 감성 분석(BERT 모델) 수행
  - 결과 예시: `positive`, `negative` + 신뢰도(`score`)
- 최근 10개의 리뷰를 감성 결과와 함께 출력

---

## 🖼️ 앱 화면 구성

### 📍 메인 페이지 (`app.py`)
- 앱 소개 및 기능 가이드 표시
- Streamlit 메뉴 기반 탐색 구조 안내

### 📍 영화 관리 페이지 (`pages/movies.py`)
- 영화 목록 표시 및 등록 폼 제공
- API 연동 실패 시 에러 메시지 및 로깅 처리

### 📍 리뷰 관리 페이지 (`pages/reviews.py`)
- 리뷰 등록 폼
- 감성 분석 결과 표시
- 선택한 영화의 최신 리뷰 10개 표시

---

## ⚙️ 프로젝트 구조

```bash
frontend/
├── app.py                  # 메인 소개 페이지
├── pages/
│   ├── movies.py        # 영화 등록 및 조회
│   └── reviews.py       # 리뷰 등록 및 조회
├── utils.py                 # 공통 유틸리티 (로거 설정 등)
```
> 📌 pages/ 디렉토리는 Streamlit의 멀티페이지 구조에 따라 자동 탐지됩니다.
>

## 🔧 실행 방법

```bash
# 1. 패키지 설치
pip install -r requirements.txt

# 2. Streamlit 앱 실행
streamlit run app.py

```

- 백엔드가 먼저 실행되어 있어야 합니다.
- 기본 API 주소: `http://127.0.0.1:8000`
    - 필요 시 `movie_page.py`, `review_page.py` 내부의 `API_URL` 수정 가능

---

## 🔒 예외 처리 및 로깅

- 각 페이지마다 상세한 로그(`DEBUG`, `INFO`, `WARNING`, `ERROR`) 출력
- 로거는 `utils.get_logger()`를 통해 공통 적용
- Streamlit 인터페이스에 사용자 친화적인 메시지 출력

---

## 🔗 백엔드 연동 API 요약

| 기능 | 메서드 | 경로 | 설명 |
| --- | --- | --- | --- |
| 영화 전체 조회 | `GET` | `/movies/` | 등록된 영화 목록 가져오기 |
| 영화 등록 | `POST` | `/movies/create_movie` | 새 영화 등록 |
| 리뷰 등록 | `POST` | `/reviews/create` | 리뷰 등록 + 감성 분석 |
| 영화별 리뷰 조회 | `GET` | `/reviews/movie/{movie_id}` | 최근 10개 리뷰 조회 |
