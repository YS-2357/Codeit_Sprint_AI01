첫 이미지 업로드시 u2net.onnx 파일이 로컬에 설치된다.

- 파이썬 환경 관련 (별도 설치해야하는 경우)
  - venv 이용
  - python -m venv myvenv
  - source ./myvenv/bin/activate
  - (myvenv) pip install -r requirements
  - (myvenv) python -m streamlit run streamlit_app.py
  - deactivate (비활성화)
